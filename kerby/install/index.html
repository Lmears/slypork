Install

Get KerBy running.

macOS

Open KerBy-macOS.pkg and follow the installer. Pick the formats you want: VST3, AU and the standalone app. It’ll ask for your admin password.

Windows

Unzip KerBy-Windows.zip, then copy the whole KerBy.vst3 folder, not the files inside it, into your VST3 folder. The default is:

C:\Program Files\Common Files\VST3

Windows asks for administrator permission there. That’s normal.

Find it in your DAW

Rescan your plug-ins and search for KerBy. In Live, hold Option (Mac) while you click Rescan.

Use the VST3 where you can. Logic and GarageBand need the AU.

Updates

Updates are free. Buyers get an email from Gumroad when a new version is out, and the download link always serves the latest build. Install it over the old one.

Remove KerBy

Delete whichever of these you installed. KerBy stores no licence and no activation, so that’s all of it.

macOS
/Library/Audio/Plug-Ins/VST3/KerBy.vst3
/Library/Audio/Plug-Ins/Components/KerBy.component
/Applications/KerBy.app
Windows
KerBy.vst3, in the VST3 folder you copied it to
